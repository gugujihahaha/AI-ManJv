# 漫剧工厂使用知识库：快速开始

> 整理自项目 README.md 与当前代码，只保留已经实现的功能。

## 软件是什么

漫剧工厂是一个本地运行的竖屏漫剧创作工具。用户提交一段剧情文本，系统调用大模型把剧情拆分成分镜稿，创作者逐格检查、修改并确认，确认后再进入后续的画面制作。当前版本完成剧情输入、分镜生成、逐格编辑与确认锁定四个环节，出图、配音、合成与导出属于后续版本。

## 运行环境

项目使用 Python 3.13、FastAPI 与 SQLite，前端是原生 HTML 和 JavaScript，不依赖前端框架。依赖清单在 requirements.txt 中。模型密钥放在项目根目录的 .env 文件里，变量名是 DEEPSEEK_API_KEY；.env 已被 .gitignore 忽略，不会提交到仓库。

## 启动步骤

在项目根目录创建并激活虚拟环境，执行 pip install -r requirements.txt 安装依赖，然后运行 uvicorn app.main:app --host 127.0.0.1 --port 8000 启动服务。服务默认监听 8000 端口，浏览器打开 http://127.0.0.1:8000/ 进入创作工作台。健康检查地址是 /health，返回 status 与版本号。停止服务时在终端按 Ctrl+C。

## 目录与入口

app/main.py 是应用入口，负责日志配置与路由挂载；app/api/projects.py 提供作品与分镜接口；app/services/storyboard.py 负责模型调用、JSON 解析与离线演示分镜；app/repository.py 封装数据读写；app/database.py 负责建表；app/static 存放页面、脚本与样式。storage 目录保存数据库和日志，不提交仓库。

## 运行测试

在项目根目录执行 python -m unittest discover -s tests -v。测试覆盖项目创建、分镜生成、逐格编辑、确认锁定、级联删除、空数据库、标题空白校验与序号冲突等场景。测试使用临时数据库，不会改动 storage 目录中的正式数据。接口文档在服务启动后可以通过 /docs 查看。
