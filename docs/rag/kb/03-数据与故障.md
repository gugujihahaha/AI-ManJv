# 漫剧工厂使用知识库：数据、日志与故障

> 整理自 app/config.py、app/database.py、app/main.py 与 app/services/storyboard.py 的实现。

## 数据保存位置

正式数据保存在 storage/manjv.db，这是一个 SQLite 数据库文件。数据库包含 projects 与 storyboards 两张表，作品与分镜是一对多关系，删除作品会级联删除它的全部分镜。分镜表的 image_path 字段为后续出图预留，当前版本不会写入图片路径。数据库路径可以通过环境变量 DATABASE_PATH 修改。

## 清空数据

清空全部作品时，先停止服务，再删除 storage/manjv.db，重新启动后 initialize_database 会自动建表，得到一个空数据库。这个操作不可恢复，删除前应备份文件。只删除某一个作品时，在作品列表使用删除按钮，或调用 DELETE /api/projects/{id}，该作品的分镜会一起删除。

## 日志位置与内容

日志写在 storage/app.log，同时输出到终端。每条业务请求记录方法、路径、状态码与耗时，例如 GET /api/projects -> 200  12ms；状态码大于等于 400 的请求记为 WARNING。未处理异常会记录完整堆栈。静态资源请求不写入日志，避免页面刷新把日志刷满。日志文件被 .gitignore 忽略，不提交仓库。

## 常见失败与处理

页面收到 422 表示请求字段不合法，通常是剧情文本不足 100 字、标题为空或时长超出范围。404 表示作品或分镜编号不存在。409 表示当前状态不允许该操作，常见于分镜不足 3 个就确认，或者确认后继续编辑。502 表示模型调用或返回结构校验失败，具体原因写在作品的 error_message 中。模型密钥无效时 DeepSeek 返回 401，后端把这次失败转成 502，并在错误信息里保留 401 与接口返回的细节。

## 网络与超时

AI 模式访问 DeepSeek 的超时时间是 55 秒，失败后自动重试一次。连接失败、代理不可用或超时都会让本次生成失败，最终表现为 502 与 storyboard_failed。demo 模式完全在本地切分，不访问网络，可以作为网络异常时的降级路径。使用助手模块的超时时间是 30 秒，失败时向调用方返回“接口返回错误”“连接失败或超时”或“返回结构异常”三类提示。

## 隐私与外部数据

发给 DeepSeek 的内容只有剧情文本、画风、目标时长，以及生成分镜时使用的系统提示。API 密钥只从 .env 读取，不写入数据库、不返回给前端、不提交仓库。项目没有账号体系，数据只保存在本机 SQLite 文件中，不会上传到其他服务器。删除数据库文件即可清除全部本地数据。
