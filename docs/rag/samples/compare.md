清空方式分两种：

2. 只删除某一个作品：在作品列表使用删除按钮，或调用 DELETE /api/projects/{id}，该作品的分镜会一起删除 [来源1]。

另外，数据库路径可通过环境变量 DATABASE_PATH 修改 [来源3]；系统没有自动备份或云同步，需要备份时停止服务后复制该文件即可 [来源2]。
